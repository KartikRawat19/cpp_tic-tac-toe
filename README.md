# C++ Tic Tac Toe

A console-based Tic Tac Toe game written in C++.

## Features

- Custom board size (3x3 to 10x10)
- Two-player gameplay
- X/O marker selection
- Input validation
- Win detection
- Draw detection
- Replay option

## How to Run

Compile:

g++ main.cpp -o tictactoe

Run:

./tictactoe
